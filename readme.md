# Meu Portal de Notícias

Projeto desenvolvido na disciplina de **Desenvolvimento Web I** — IFC Campus Araquari.

## Sobre o projeto

Um pequeno portal de notícias com três páginas: uma com artigos sobre programação,
uma com meus hobbies e uma de perfil, no estilo de uma página profissional (como o LinkedIn).

## Páginas

- `index.html` — Página inicial, com artigos sobre programação, banco de dados e
  segurança de redes.
- `hobbies.html` — Galeria de cartões com os hobbies que faço no meu tempo livre.
- `perfil.html` — Perfil pessoal, com foto de capa, foto de perfil, sobre mim,
  formação, competências e interesses.

## Estrutura de pastas

```
portal/
├── index.html
├── hobbies.html
├── perfil.html
├── css/
│   ├── reset.css      # zera os estilos padrão do navegador
│   ├── global.css     # estilos compartilhados (cabeçalho, menu, rodapé)
│   ├── style.css       # estilos da página inicial
│   ├── hobbies.css     # estilos da página de hobbies
│   └── perfil.css      # estilos da página de perfil
└── img/
    ├── programacao/
    ├── hobbies/
    └── perfil/
```

## Conteúdos aplicados até aqui

- HTML semântico (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`)
- Elementos em bloco e inline
- `div` e `span`
- Flexbox (`display: flex`, `flex-wrap`, `gap`)
- Cartões de conteúdo com CSS
- Imagens adaptáveis (`object-fit`, `width: 100%`)

## Como visualizar

Basta abrir o arquivo `index.html` no navegador. As demais páginas são acessadas
pelo menu de navegação no topo.
